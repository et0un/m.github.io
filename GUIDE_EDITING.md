# Краткая памятка по редактированию курса

## Темы

Основной список тем хранится в `topics.js`, но удобнее редактировать его через `/studio/`.
Номера тем и общее количество рассчитываются автоматически.

## Лекции

Файлы лекций находятся в `lectures/`. Studio умеет создавать и публиковать их автоматически.

## Картинки

Локальные изображения хранятся в `assets/images/`. При добавлении изображения с компьютера Studio автоматически формирует корректный путь для лекции.

## Видео

Используйте в Studio кнопку `Видео YouTube / Vimeo`. Обычные ссылки YouTube/Vimeo автоматически переводятся в embed-формат.

## Удаление медиа

Нажмите на фото/видео в предпросмотре → `Удалить медиа`.

## Публикация

Самый быстрый способ: `Studio → Публикация GitHub → Опубликовать на GitHub`.
Резервный способ: скачать HTML/ZIP и загрузить файлы вручную в GitHub.
