# Моушн-дизайн — GitHub Pages (v18)

## Что изменилось в v18

Темы теперь управляются централизованно из `topics.js`.

- Нумерация `01`, `02`, `03` вычисляется автоматически по порядку объектов в `topics.js`.
- Общее количество тем вычисляется автоматически.
- Порядок бокового меню и кнопок «предыдущая / следующая» берётся из `topics.js`.
- Название темы, её номер и теги на странице лекции берутся из `topics.js`.
- В папке `lectures` есть `_template.html` для создания новых лекций.

## Главное правило

`slug` в `topics.js`, имя HTML-файла и `data-topic` страницы должны совпадать.

Пример:

```js
{slug:"camera-animation", title:"Анимация камеры", tags:["Практика"]}
```

Файл:

```text
lectures/camera-animation.html
```

Внутри файла:

```html
<body class="lecture-page" data-topic="camera-animation">
```

## Добавить тему

1. Скопируйте `lectures/_template.html`.
2. Переименуйте копию, например в `camera-animation.html`.
3. Внутри замените `data-topic="YOUR-SLUG"` на `data-topic="camera-animation"`.
4. Добавьте объект в `topics.js` в нужное место.
5. Заполните содержание лекции.

Номер присвоится автоматически.

## Удалить тему

1. Удалите объект темы из `topics.js`.
2. Удалите соответствующий HTML-файл из `lectures/`.

Остальные темы автоматически перенумеруются, а переходы обновятся.

## Поменять порядок

Просто переставьте объекты в `topics.js`. Не переименовывайте slug и HTML-файлы.

## Переименовать тему

Измените только `title` в `topics.js`. Название на главной, в боковом меню, в заголовке лекции и `<title>` браузера обновится автоматически.

## Теги

Меняются в `topics.js`:

```js
tags:["Актуально", "Теория"]
```

Если теги не нужны:

```js
tags:[]
```

## Важно про slug

Slug — технический постоянный идентификатор. Его не нужно менять при перестановке темы. Старые slug вроде `08-graph-editor` могут остаться такими даже если визуально тема станет №05: отображаемый номер всё равно будет вычислен автоматически.


## Визуальный редактор

Редактор находится по адресу `studio/` (например, `https://YOUR-NAME.github.io/YOUR-REPO/studio/`). На публичных страницах ссылки на него нет, а сама страница содержит `noindex`.

Важно: GitHub Pages — статический хостинг. Вход в редактор реализован на стороне браузера и предназначен как удобная блокировка интерфейса, а не как защита секретных данных. Не храните внутри редактора приватные данные.

Редактор умеет загружать опубликованную лекцию, редактировать текст в живом предпросмотре, вставлять картинки/видео/ссылки, скачивать готовый HTML лекции и новый `topics.js`. Для публикации скачанные файлы нужно загрузить в GitHub вручную.
