# Studio: текст, медиа и шрифты

Откройте `/studio/` и войдите с прежними данными. Инструменты текста и медиа доступны в режимах **Лекции**, **Главная страница** и **Страницы ссылок**.

## Текст

- Выделите текст и примените размер, шрифт, начертание, цвет букв или цвет выделения.
- Без выделения эти настройки меняют текущий абзац. Кнопки «Заголовок», «Абзац», «Цитата» и списки меняют тип блока.
- «Ссылка» открывает окно с адресом, текстом и выбором новой вкладки. Адрес существующей ссылки можно изменить, поставив курсор внутрь неё. «Убрать ссылку» сохраняет её текст.
- «Сбросить стиль» удаляет оформление выделенного текста. «Без выделения» убирает только цвет фона.
- При вставке из других редакторов сохраняются абзацы, списки, жирный текст, курсив и ссылки; чужие шрифты и цвета очищаются, чтобы текст соответствовал курсу.

Исправлены потеря выделения при нажатии кнопок, применение размера к несохраняемому контейнеру редактора и превращение новых абзацев в неоформленные блоки. При последовательном применении размера, цвета и шрифта предыдущие настройки сохраняются.

## Изображения и GIF

### Превью каждой темы на главной

Во вкладке «Лекции» выберите тему и нажмите **«Загрузить превью»** в блоке «Превью темы на главной». Изображение появится на карточке этой темы в списке тем. Оно не добавляется в текст лекции или в её боковое меню. Исходная картинка сохраняется отдельно, а для карточки автоматически используется кадр по центру.

**«Опубликовать превью»** загружает картинки и обновляет `topics.js`, не изменяя HTML лекций. **«Скачать ZIP превью»** сохраняет тот же набор файлов для ручной загрузки. Превью также входит в обычный ZIP лекции и её публикацию. **«Убрать превью»** возвращает стандартную декоративную картинку; опубликуйте изменение, чтобы оно появилось на сайте.

Настройки превью и исходные файлы восстанавливаются после перезагрузки Studio и при переходе между темами.

Нажмите **«Фото / GIF / видео»**, выберите файлы, расположение, ширину и подпись. Для двух изображений рядом выберите сразу два файла и расположение «Два рядом». GIF сохраняется как исходный файл, анимация не преобразуется в картинку.

Нажмите на изображение в предпросмотре. В панели **«Выбранное медиа»** можно:

- изменить ширину блока от 20% до 100% ширины текста;
- переключить один или два столбца;
- изменить подпись и описание изображения;
- добавить второе изображение рядом;
- удалить выбранное медиа.

Подпись также редактируется прямо под изображением. Описание изображения используется для доступности и отличается от видимой подписи. На узком экране два столбца превращаются в один, чтобы изображения оставались читаемыми.

Изображения можно вставлять из буфера обмена и перетаскивать в текст. «Медиа по URL» позволяет вставить уже размещённый файл.

## Видео

Загружайте собственные MP4, WebM или Ogg через ту же кнопку. На странице появится плеер с обычными элементами управления и подписью. Совместимость кодека определяется браузером; наиболее удобны MP4 с H.264 и WebM. Для прямой загрузки через Studio файл должен быть не больше 90 МБ. Более крупное видео разместите отдельно и вставьте URL.

В «Медиа по URL» выберите «YouTube / Vimeo / Rutube / VK» для встроенного плеера или «Видеофайл MP4 / WebM» для прямой ссылки на файл. Готовый iframe-код не исполняется как HTML; для поддерживаемого провайдера используется его адрес видео.

## Код

«Блок кода» открывает окно с названием языка и текстом кода. Сохраняются отступы, переносы, символы `<`, `>` и `&`. Код показывается отдельным блоком с моноширинным шрифтом. Двойной клик по блоку в Studio открывает его для изменения. Tab добавляет два пробела, Ctrl+Enter выходит в следующий абзац. На опубликованной странице студенты могут нажать «Копировать».

## Google Fonts

«Шрифт текста» меняет выделенный фрагмент или текущий абзац. Есть семейства с кириллицей, курсив и разные веса. У PT Sans и PT Serif доступны обычное и жирное начертания. В пункте «Другой из Google Fonts…» введите точное название семейства с [Google Fonts](https://fonts.google.com/?subset=cyrillic). Набор начертаний и поддержка кириллицы зависят от семейства.

В общей панели **«Шрифт всего сайта»** выберите или введите семейство. Предпросмотр меняется сразу. Кнопка «Применить ко всему сайту» публикует `site-settings.js` через подключение GitHub. Можно скачать этот файл и загрузить его в корень репозитория вручную. Настройка применяется к главной, всем лекциям и страницам ссылок; явно выбранные шрифты отдельных фрагментов сохраняются.

Подключение использует [официальный Google Fonts CSS API](https://developers.google.com/fonts/docs/css2). При недоступности сервиса браузер использует системный запасной шрифт.

## Черновики, ZIP и публикация

Текст сохраняется локально автоматически; файлы медиа сохраняются в IndexedDB этого браузера. После перезагрузки Studio восстанавливает последнюю лекцию и черновики главной и страниц ссылок. «Загрузить опубликованную» заменяет текущий текст опубликованным. Черновики не переносятся автоматически на другое устройство.

«Опубликовать на GitHub» сначала загружает используемые медиа и затем HTML страницы. Нужен токен с Contents: Read and write для репозитория. Токен остаётся только в текущей вкладке, как и раньше.

Во всех трёх режимах есть ZIP с HTML и используемыми локальными медиа. Загружайте содержимое ZIP в соответствующие папки репозитория, сохраняя структуру: `assets/images`, `assets/videos`, `lectures` или `resources`. Только HTML не содержит сами файлы медиа. Если браузер не позволяет сохранять файлы или не хватает места, скачайте ZIP перед закрытием вкладки.

При первоначальном обновлении Studio загрузите всю подготовленную версию сайта: кроме HTML изменены стили и редактор и добавлены `studio/rich-editor.js`, `site-settings.js`, `course-design.js`.
