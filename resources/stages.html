Примерные темы для курсовых работ

При выборе темы рекомендуется связать моушн-дизайн с конкретным объектом, задачей или средой применения.

Например: «Разработка системы анимированных элементов для оформления сообщества “Хочу в Гуманитарный” в социальной сети VK».

Вместо обобщённой темы студент может выбрать реальный или учебный бренд, культурный проект, музыкального исполнителя, мобильное приложение, медиаресурс или социальную инициативу. Тему обязательно согласовывать с преподавателем.

Идеальная форммула:

Разработка [анимированного продукта] для [бренда или проекта] с целью [задача]

- Разработка навигационных переходов для сайта виртуальной выставки

- Проектирование анимации статусов и уведомлений для приложения доставки

- Создание анимированных подсказок для интерфейса сервиса бронирования

- Разработка системы анимированных иконок для городского информационного портала
